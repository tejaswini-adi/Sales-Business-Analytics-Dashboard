# Sales Business Analytics Dashboard

## Project Overview
This project is an interactive Business Analytics Dashboard developed using Power BI. The dashboard helps analyze sales performance, customer behavior, profit trends, and business KPIs for better decision-making.

## Features
- Sales performance analysis
- Revenue and profit tracking
- KPI monitoring
- Region-wise sales insights
- Customer segmentation
- Interactive filters and slicers
- Data visualization using charts and graphs

## Tools & Technologies Used
- Power BI
- Microsoft Excel / CSV
- Data Cleaning
- Data Visualization
- Business Analytics

## Dashboard Insights
- Identified top-performing products and regions
- Analyzed monthly sales trends
- Tracked profit margins and revenue growth
- Compared sales performance across categories

## Project Workflow
1. Data Collection
2. Data Cleaning
3. Data Transformation
4. Dashboard Design
5. KPI Visualization
6. Business Insights Generation
